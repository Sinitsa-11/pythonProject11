English Learning App
Учебное desktop-приложение для изучения английского языка. Проект написан на Python с использованием PyQt5 и SQLite.
В приложении предусмотрены две роли пользователей — учитель и ученик. В зависимости от роли доступны разные функции: работа с заданиями и учениками, выполнение заданий и просмотр результатов.

Основные возможности
Учитель может:
-добавлять, изменять и удалять задания;
-просматривать список заданий;
-добавлять и удалять учеников;
-искать ученика по ФИО;
-просматривать оценки за отдельные задания;
-просматривать средний балл учеников.
Ученик может:
-выбирать задания по их номерам;
-просматривать условия и варианты ответа;
-выполнять задания;
-получать результаты и оценки;
-смотреть свои оценки;
-смотреть свой средний балл.

Технологии
1. Python — основная логика приложения
2. PyQt5 — графический интерфейс
3. SQLite — хранение данных
4. SQL — работа с базой данных
5. Qt Designer — создание интерфейсов окон

Особенности реализации
В приложении реализована авторизация пользователей с разделением по ролям. После входа пользователь получает доступ только к функциям, которые соответствуют его роли.
Интерфейс приложения состоит из нескольких окон. Их внешний вид создавался в Qt Designer и сохранялся в `.ui`-файлах, а логика работы с ними реализована в Python.
Для хранения данных используется SQLite. В базе находятся отдельные таблицы для пользователей, заданий и результатов выполнения.
Результат выполнения задания рассчитывается программой автоматически: ответ ученика сравнивается с правильным ответом из базы данных, после чего выставляется оценка.

База данных
Для работы приложения используется SQLite.
Основные таблицы:
-`logs` — пользователи, их логины, пароли, роли и данные учеников;
-`exercises` — задания, варианты ответов и правильные ответы;
-`grades` — результаты выполнения заданий.
Результаты сохраняются в базе данных, поэтому оценки можно просматривать после завершения задания.

Запуск
Для запуска проекта необходим Python и библиотека PyQt5.
Установить зависимость можно командой: pip install PyQt5
После установки запустить приложение: python main.py
Также проект можно открыть в PyCharm и запустить `main.py`.
Файл `569.sqlite` должен находиться в той же директории, что и `main.py`.
